## Acceptance and implementation contract

- `/matches`: signed-in coach sees their own active, waiting and completed matches, with clear resume/invitation/replay links, opponent/open-seat labels and recorded results. Joined SQL query scopes both seat roles and avoids per-match lookups. Keep existing creation/game choice flow and finished-record semantics for other callers.
- Invitations: match page provides Copy match link and a visible selectable URL. Clipboard denial/absence selects the link and explains manual copying. Opening/copying never joins. Waiting copy differs for creator, eligible coach and signed-out spectator. Sign-in/register links preserve only a validated local match path through authentication; joining stays an explicit POST. No opponent is committed without their Join.
- Consequences: timeline metadata comes from adjacent authoritative positions at each event, with caller visibility applied. Show actual Checkers capture counts/promotions and Fleet newly sunk ship lengths. Earlier hits remain earlier hits after reload/reconnect, and hidden placements remain redacted. Both length-three ships are distinct. No inferred agent reasoning.
- Winning lines: highlight complete winning Tic/Four lines on the currently displayed board; respect first-seat mapping and Four row orientation. Draws, unfinished history and forfeit-only results do not invent winning cells. Retain existing coordinate/accessibility labels and caption-only board reuse.
- Post-match: clearly labelled Final match summary uses recorded result and factual per-agent actions/consequences; works on initial finished load and live completion. Edit agent leads to the existing editor. Create rematch requires a signed-in participant and a finished source, creates a new waiting invitation for the same game with the requesting coach only, snapshots current coaching when a later coach joins, and never starts model work on creation. Reject missing source/unfinished/nonparticipant/signed-out requests without writing. Public summary contains no hidden cells, email or private provider data.
